# AION2総合サポートツール v3.8 — クーポン・Drops自動取得

## この版の動作

- GitHub Actions が **6時間ごと**（UTC 01:17, 07:17, 13:17, 19:17）に公開情報を確認します。
- 取得元：AION2 Global公式SteamニュースAPI/RSS、公開NCSOFT Global公式掲示板、PURPLE Loungeの公開告知、AION2_JP公開投稿の外部ミラー（※参考情報扱い）。
- `scripts/update_rewards.py` が `data/rewards.json` を更新し、GitHub Actions がこのファイルだけをコミットします。
- サイトは起動時に同一オリジンの `data/rewards.json` を読み込み、表示中も30分以上経過時／復帰時に再読み込みします。
- 受信できない時は、画面で「失敗」「最終成功日時」「一部取得失敗」を明示します。受信失敗を「開催なし」とは判定しません。
- 以前の使用済みチェック、手動追加、ペット・マップ・イベント・装備厳選の既存コードは維持します。
- 公開X投稿の外部表示とNCSOFT内部公開APIは非公式の取得手段であり、配信元の仕様変更で失敗する場合があります。グローバル版以外の情報を自動登録しません。
- **有効期限が「メンテナンス前」など時刻未定の場合は日付のみを表示し、「使用可能」と断定しません。**
- サイト上の自動取得は**公開時にのみ実現**します。HTMLを単体で開いた場合は内蔵のサンプル確認データを表示し、自動配信の取得は行えません。

## GitHub反映時に変更／追加するファイル

1. `index.html` — クーポン／Drops表示と新しい自動更新ロジック
2. `sw.js` — PWAキャッシュ識別子をv3.8に更新
3. `data/rewards.json` — 初回の確認済みデータ（定期取得で更新）
4. `scripts/update_rewards.py` — 公開ニュース収集・日付抽出・出力処理
5. `.github/workflows/update-rewards.yml` — 定期実行と結果のコミット

GitHub Actionsの「ワークフロー読み書き」権限、`main`へのbotコミット権限が必要です。GitHub側の設定でbotに書込み権限がない場合は、Actionsの実行履歴にエラーが表示されます。GitHubのスケジュールは負荷により遅延する場合があります。

## 検証

- `python -m unittest discover -s tests -v` — ニュース抽出、誤検出防止、重複イベント除去、通信失敗時のスナップショット保持。
- Playwright (Chrome)のPC幅1365px、スマホ幅390pxで、JSONモックによる自動表示、クーポン・Dropsの描画、既存の装備厳選・ホームへの遷移を確認。
- JavaScript構文検査を実行。
- GitHub Actionsの本番通信と実行は**未検証**（公開後の検証が必要）。
